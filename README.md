# Store of Scope plugins

The public manual-install marketplace for [Store of Scope](https://storeofscope.com). It includes the newsletter-reading product and practical skills from Asad’s work at Noodle Seed.

## Install

```bash
codex plugin marketplace add asadatnoodle/store-of-scope-plugins
codex plugin add store-of-scope@store-of-scope
```

Open a new task and say:

```text
Set up Store of Scope.
```

## What is included

- the Store of Scope product and setup skills;
- the hosted Store of Scope MCP connection;
- guided Gmail setup, with Calendar and Drive remaining optional; and
- approval boundaries for ingestion, delivery, unattended sends, scheduling, and retirement.

Users install Store of Scope. Noodle Seed hosts the MCP infrastructure and is not a separate end-user installation.

## Release boundary

This repository provides the public manual marketplace. Listing in the universal ChatGPT and Codex Plugins Directory is a separate submission and review process.

## Meta ads workflow

Bring your company’s brand guide, product context and design/content skills into Codex. Prepare creative, define an experiment, create paused Meta campaigns when authorized, and review results with clear measurement boundaries. Meta hosts the official Ads MCP; this plugin supplies the reusable workflow.

```sh
codex plugin marketplace add asadatnoodle/store-of-scope-plugins
codex plugin add meta-ads-workflow@store-of-scope
```

If already registered, refresh the marketplace with `codex plugin marketplace upgrade store-of-scope`. Start a new Codex task and say: “Use $meta-ads-workflow to prepare a local campaign brief and creative review pack for my company.”

[Skill source and installation options](plugins/meta-ads-workflow/README.md) · [Workflow and download](https://storeofscope.com/skills/meta-ads-workflow/)

This skill includes no MCP server, account credentials or Noodle Seed brand assets. You supply your own Meta permissions and production tools. Installation does not create campaigns or authorize spending.
