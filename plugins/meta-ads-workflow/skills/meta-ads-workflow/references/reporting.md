# Reporting and the next experiment

Use authenticated, current read-only evidence for a performance request. State the cutoff, date range, account timezone, currency and attribution window. Keep unavailable values distinct from zero; name stale snapshots as historical. Token expiry does not stop existing campaigns from spending.

Read the Campaign → Ad set → Ad hierarchy, effective states, budgets/caps, spend, delivery errors and test membership. Report at the level the decision needs. Do not add campaign totals to the same ad-set/ad spend, or pool countries whose tests differ. Separate daily budgets, lifetime allocations and account-wide limits.

Show spend, impressions, clicks, landing-page views and the requested conversion metric with clear definitions. Derive rates only from compatible scopes and denominators. Meta-attributed Leads or purchases are platform reports; confirmed signups, qualified customers and revenue require first-party evidence and a defensible match. Explain tracking or reconciliation gaps.

Compare the actual variable tested and disclose uneven delivery or incomplete randomized membership. A provider winner badge is not automatically 95% confidence. Small samples can remain inconclusive. Return the result, evidence, limitations and one proposed next experiment.

Do not activate, pause, increase budgets, replace media or alter tracking as a side effect of reporting. Execute a change only within the user’s specific authorization. A recurring report additionally needs a destination, timezone, schedule and authorization; the downloadable skill does not create an unattended job.
