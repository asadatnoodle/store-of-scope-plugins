# Campaign review record template

## Decision requested
State the exact next action, selected account and objects, total allocation, currency, budget type and dates. Reference existing authorization; ask only for a decision still missing or materially changed.

## Creative and configuration
For each variant record country/cell, creative and ad IDs when created, source/export paths, asset hash, copy, CTA, destination/UTMs, placements and intended audience. Link the phone-size preview and the editable source. Record asset rights and any required declarations.

- Cutoff and timezone:
- Local-only artifacts or remote objects created:
- Campaign / ad set / ad IDs and effective statuses:
- Budget amounts/types and total reconciliation:
- Schedule readback and expired-date check:
- Review, processing, billing or delivery issues:
- Study cells and actual variable being tested:
- Tracking and first-party measurement evidence or gaps:
- Redacted receipts and unresolved write outcomes:

## Approval and execution
- Exact scope approved, approver and timestamp:
- Material changes since approval:
- Activation requested / supported / executed / unknown:
- Effective status after execution:
- Actual delivery evidence, if available:
- Next review or manual handoff:

Paused creation is not launch. Active configuration is not delivery. Record partial outcomes when only some objects were changed; reconcile before retrying.
