# From company context to a useful experiment

## Keep the brand context close

Read the company’s current copy rules, colors, fonts, logos, examples, product facts and claims evidence. Record the source paths and what is approved. A reusable brand skill can carry those decisions into future campaigns, but the company owns them. This package contains no Noodle Seed artwork or private design system.

Use available company skills for copy and asset production. Choose static, motion or both for the placement and experiment; do not assume access to a particular renderer, image model or subscription. Keep text and official identity assets exact and editable. Inspect the actual exports at feed and phone size, with readable contrast, safe cropping and a clear next action. Check current Meta media requirements before upload. Review applicable AI-content declarations and policy requirements accurately; do not inherit an old campaign’s disclosure choice.

## Define what is being tested

Write one hypothesis and a primary decision metric. Specify the variable that changes and the parts held constant: offer, audience, destination, attribution and schedule. A different opening sentence is a copy test. Two ads using the same film are not different video hooks.

If separate country budgets matter, propose explicit allocations whose sum matches the authorized total and identify whether each is daily or lifetime. A proposal is not approval. Use the account’s currency and timezone; convert dates explicitly. Avoid assigning an unsupported budget schedule just to satisfy a tool.

If a randomized split study is needed, verify current eligibility, cell membership and study windows with the provider. Multiple ads in an ad set can receive uneven delivery; they do not by themselves establish a randomized A/B test. For small budgets, describe the work as exploratory when appropriate. Set a review date and stopping criteria rather than promising statistical significance.

## Produce a review pack

For each named variant include primary text, headline, description if used, CTA, final destination with tags, asset file/hash and preview. Supply editable source alongside exports. Preserve the approved brand and message while changing only the intended variable.

For media replacement, inspect current tool capabilities. If the platform requires a new creative/ad, leave superseded objects paused and preserve intended ad-set/study membership. Re-read the result. Do not silently change a running experiment; agree a new phase when the change affects interpretation.

## Worked example: Noodle Seed

The workflow was used to prepare three country campaigns for the US, Pakistan and India, with separate lifetime allocations and two primary-text variants in each market. Six ads shared a temporary film, so the difference was copy rather than video. The campaigns were created paused for review. Campaign objects were created through Meta’s MCP; local media used a Graph API upload because that client could not upload files through MCP.

This describes a historical setup, not current delivery or performance. Asad’s reported two-week-to-two-hour change is his personal workflow experience, not a guaranteed setup time, Meta review time or campaign result. Each company supplies its own brand system, tools and approvals.
